
## Réseau 101
### Bloc CIDR(ClassLess Inter-Domain Routing) ou Routage inter-domaines sans class
- Le bloc CIDR permet d'identifier les bloc d'adresse IP
- Le CIDR permet entre autre d'identifier les adresses IP qui seront utiliser dans le VPC et la taille de ces adresses IP
- Le CIDR permet aussi de diviser les adresses IP en bloc de petite taille facile à gérer.
- 192.168.0.0/16(Chaque adresse contiendra(192.168) reprensentant les 16bits du masque du sous réseau alors que les chiffres restant(0.0) vont changer)
